# Icon fonts

`icons-regular.woff2` and `icons-solid.woff2` are generated by
`tools/icons/build.py` (`make icons`) from Google's Material Symbols
(Outlined), Apache License 2.0, https://github.com/google/material-design-icons.
They contain only the glyphs Elastic uses, placed at the Font Awesome code
points Elastic's stylesheets refer to. Do not edit; rebuild instead.
